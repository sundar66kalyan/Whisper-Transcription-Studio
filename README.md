# Whisper Transcription Studio

A free video and audio transcription application powered by Faster-Whisper.

## Features

- Transcribe video and audio files
- Tamil and English transcription
- Automatic language detection
- Tiny, Base and Small Whisper models
- Export transcripts as TXT, SRT, VTT and JSON
- CPU-based inference
- No paid transcription API required

## Requirements

- Python 3.11
- FFmpeg
- Windows for local installation
